# v21-v22 変更内容

## 概要
v21-v21で発生した「送信後にステップ5（外壁材選択）に戻る」問題を修正しました。

## 問題の原因

### v21-v21での問題
送信ボタンをタップすると、数秒間「送信中...」と表示された後、ステップ5（外壁材選択）に戻ってしまう。

### 原因
`submitAll()` 関数の551行目で、送信成功後のステップ番号が古いままでした:

```javascript
// 誤り（v21-v21）
model.step = 5; render();
```

v21-v21では8ステップ構成に変更したため、ステップ5は「外壁材選択」になっています。
完了画面は**ステップ9**です。

### ステップ番号の対応
- ステップ0: イントロ
- ステップ1: 連絡先
- ステップ2: 希望内容
- ステップ3: 築年数
- ステップ4: 階数
- ステップ5: 外壁材 ← ここに戻っていた
- ステップ6: 図面アップロード
- ステップ7: 写真アップロード
- ステップ8: 確認画面
- **ステップ9: 完了画面** ← ここに進むべき

## 修正内容

### public/liff.js

**変更箇所:** 551行目

```javascript
// 修正前
model.step = 5; render();

// 修正後
model.step = 9; render();
```

送信成功後、ステップ9（完了画面）に進むように修正しました。

## トラブルシューティング

### 送信後も外壁材選択に戻る場合
1. ブラウザのキャッシュをクリア（Ctrl+Shift+Delete）
2. LINEアプリを完全に終了して再起動
3. Renderのデプロイログで最新のコミットが反映されているか確認

### 完了画面が表示されない場合
1. ブラウザの開発者ツール（F12）でコンソールエラーを確認
2. `renderDone()` 関数が正しく定義されているか確認（580-585行目）
3. `render()` 関数で `return renderDone();` が呼ばれているか確認（67行目）
