# v21-v23 変更内容

## 概要
外壁材のタイトルを変更し、屋根材選択ステップを追加しました。屋根材も外壁材と同じく画像付きグリッド形式で選択できます。

## 新しいステップ構造

### 変更前（v21-v22: 8ステップ + 完了画面）
1. 連絡先
2. 希望内容
3. 築年数
4. 階数
5. 外壁材
6. 図面アップロード
7. 写真アップロード
8. 確認画面
9. 完了画面

### 変更後（v21-v23: 9ステップ + 完了画面）
1. 連絡先
2. 希望内容
3. 築年数
4. 階数
5. **現在の外壁材**（タイトル変更）
6. **現在の屋根材**（新規追加）← 画像付きグリッド選択
7. 図面アップロード
8. 写真アップロード
9. 確認画面
10. 完了画面

## 主な変更点

### 1. 外壁材のタイトル変更（liff.js）

**変更前:**
```html
<h2>外壁材をお選びください</h2>
```

**変更後:**
```html
<h2>現在の外壁材をお選びください</h2>
```

### 2. 屋根材選択ステップを追加（liff.js）

**新しいステップ6: 現在の屋根材**

4つの選択肢を画像付きグリッドで表示:
- 和瓦
- スレート瓦
- 金属屋根
- セメント瓦

**デザイン:**
- 外壁材と同じ画像付きグリッドレイアウト
- 2列グリッド
- 各選択肢に画像とラベル
- タップで選択
- 「見た目が近いものを選んでください（画像はサンプルです）」の説明文

### 3. 屋根材の画像を生成

4種類の屋根材画像を生成し、`/img/`ディレクトリに配置:
- `japanese_tile.png`: 和瓦（黒い曲線の瓦）
- `slate_tile.png`: スレート瓦（平らな長方形の瓦）
- `metal_roof.png`: 金属屋根（波型の金属パネル）
- `cement_tile.png`: セメント瓦（平らなコンクリート瓦）

### 4. ステップ番号を更新

**すべてのステップで badge を更新:**
- ステップ1: `1/9`（連絡先）
- ステップ2: `2/9`（希望内容）
- ステップ3: `3/9`（築年数）
- ステップ4: `4/9`（階数）
- ステップ5: `5/9`（現在の外壁材）
- ステップ6: `6/9`（現在の屋根材）← 新規
- ステップ7: `7/9`（図面アップロード）
- ステップ8: `8/9`（写真アップロード）
- ステップ9: `9/9`（確認画面）
- ステップ10: 完了画面

### 5. 確認画面に屋根材を追加（liff.js）

**確認画面の表示項目:**
- お名前
- 電話番号
- 郵便番号
- 住所
- お見積もり希望の内容
- 階数
- 築年数
- **現在の外壁材**（ラベル変更）
- **現在の屋根材**（新規追加）
- アップロードしたファイル

### 6. 送信処理に屋根材を追加（liff.js, routes/details.js）

**liff.js - submitAll関数:**
```javascript
fd.append('roofMaterial', model.form.roofMaterial);
```

**routes/details.js - バックエンド受信:**
```javascript
const { ..., roofMaterial } = req.body || {};
```

**メール内容に追加:**
```html
<p><b>・現在の屋根材</b><br/>${roofMaterial || '（未回答）'}</p>
```

1. 変更ファイルをプロジェクトにコピー:

2. Gitにコミット&プッシュ:
```bash
cd line-paint-estimator-main

git commit -m "v21-v23: 屋根材選択ステップを追加、外壁材タイトル変更"
```

3. Renderで自動デプロイを確認

4. **重要: ブラウザのキャッシュをクリア**

   - LINEアプリを完全に終了して再起動

## 期待される効果

### ユーザー体験の改善
1. **より詳細な情報収集**: 外壁材だけでなく屋根材も選択できる
2. **視覚的に分かりやすい**: 屋根材も画像で選択可能
3. **入力精度の向上**: 屋根材の名前を知らなくても見た目で選択できる

### 見積もり精度の向上
1. **屋根材の情報**: 屋根工事の見積もりに必要な情報を事前に収集
2. **外壁材の明確化**: 「現在の」という表記で、現状の材質を明確に
3. **詳細な情報**: 外壁塗装と屋根工事の両方に対応

## トラブルシューティング

### 屋根材の画像が表示されない場合
1. `/img/`ディレクトリに以下の画像があるか確認:
   - japanese_tile.png
   - slate_tile.png
   - metal_roof.png
   - cement_tile.png
2. 画像のパスが正しいか確認（/img/japanese_tile.png など）
3. ブラウザのキャッシュをクリア

### ステップ番号がおかしい場合
1. すべてのbadgeが/9になっているか確認
2. ブラウザのキャッシュをクリア
3. LINEアプリを再起動

### 送信後に外壁材選択に戻る場合
1. submitAll関数で`model.step = 10`になっているか確認
2. ブラウザのキャッシュをクリア

## 注意事項

### 画像ファイルのサイズ
生成された画像は各1.2MB〜1.5MBです。必要に応じて圧縮してください。

### v21-v22からの変更点
v21-v23は**v21-v22の拡張版**です。v21-v22の修正（送信完了後の画面遷移）も含まれています。

### CSSの依存関係
屋根材選択は外壁材選択と同じCSSクラスを使用します:
- `.grid-choice`
- `.grid-item`
- `.selected`

これらのCSSクラスが定義されていることを確認してください（styles.css）。
