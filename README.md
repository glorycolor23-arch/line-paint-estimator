## 🚀 デプロイ手順

### 1. GitHub Desktopでファイルを配置
1. **Repository → Show in Finder** でリポジトリフォルダを開く
2. ZIPファイルを解凍して、**4つのファイル全て**を配置:
   - `routes/estimate.js` → リポジトリの `routes` フォルダに**上書き**
   - `routes/details.js` → リポジトリの `routes` フォルダに**上書き**
   - `public/liff.js` → リポジトリの `public` フォルダに**上書き**
   - `lib/sheets.js` → リポジトリの `lib` フォルダに**上書き**

### 2. コミット&プッシュ
3. GitHub Desktopでコミット:
   - Summary: `v18: UI改善、LINEメッセージ変更、メール送信処理改善`
4. **Push origin** をクリック

### 3. Renderで自動デプロイを確認
5. Renderのダッシュボードでデプロイログを確認
6. ビルドエラーがないことを確認

### 4. もしLINEメッセージが変わらない場合
7. Renderのダッシュボードで **Manual Deploy** → **Deploy latest commit** をクリック
8. 手動再デプロイを実行

## ⚠️ 既知の問題

### メール送信が届かない
**問題**: 管理者メールアドレス(matsuo@graphity.co.jp)にメールが届かない

**原因**: RenderのIPアドレスがXserver SMTPサーバーにブロックされている可能性

**現在の設定**:
```
SMTP_HOST=sv16187.xserver.jp
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=line-paint@graphity.co.jp
SMTP_PASS=aM.q2eGzmjM=
SMTP_FROM=line-paint@graphity.co.jp
ADMIN_EMAIL=matsuo@graphity.co.jp
```

**対応策**:

#### 1. ポート587(STARTTLS)を試す
Renderの環境変数を以下に変更:
```
SMTP_PORT=587
SMTP_SECURE=false
```

#### 2. SendGridを使用(推奨)
XserverのSMTPがRenderからブロックされている場合、SendGridなどの別のサービスを使用する必要があります。

**SendGridのメリット**:
- 無料プラン: 100通/日
- Renderとの相性が良い
- IPアドレスの評価が高い

**現状**:
- LINEメッセージは正常に送信されているので、問い合わせ内容は確認できます
- メール送信は裏で実行されるため、ユーザー体験には影響しません
