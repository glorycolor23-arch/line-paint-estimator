# 外壁塗装見積もりシステム 修正ファイル v16

## ✨ v16の新機能

### 1. LINEメッセージを2つの吹き出しに変更 ✅
**ファイル**: `routes/estimate.js`

概算見積もり完了後のLINEメッセージを、3つの吹き出しから2つに変更しました。

**1つ目の吹き出し**:
```
外壁塗装オンライン見積もりにご連絡ありがとうございます。
ご連絡いただいた内容の概算見積もりは以下の通りです。

【回答内容】
・お見積もり希望内容
　外壁塗装（回答した内容を掲載）
・築年数
　11〜15年（回答した内容を掲載）
・階数
　2階建て（回答した内容を掲載）
・外壁材
　モルタル（回答した内容を掲載）

概算見積もり金額
¥000,000（計算した金額）
```

**2つ目の吹き出し**(ボタンテンプレート):
```
より詳しいお見積もりをご希望の方はこちら。
こちらのフォームに回答いただくと、現地調査での訪問は行わず正確な工事金額をご提示いたします。
ご提示した見積額で発注も可能です。

[ボタン] 無料で、現地調査なしの見積もりを依頼
```

### 2. 建物写真アップロード画面のスクロール位置を最上部に ✅
**ファイル**: `public/liff.js`

図面アップロード画面と建物写真アップロード画面に遷移した際、ページの最上部を表示するように修正しました。

**変更内容**:
- `renderDrawings()`と`renderPhotos()`の先頭に`window.scrollTo(0, 0);`を追加

### 3. ファイル選択ボタン間に区切り線を追加 ✅
**ファイル**: `public/liff.js`

図面アップロード画面と建物写真アップロード画面で、各ファイル選択ボタンの間に薄い区切り線を追加しました。

**変更内容**:
- 各ファイル選択セクションの間に`<hr style="border:none;border-top:1px solid #e0e0e0;margin:20px 0;">`を追加

### 4. 送信中の画面を表示 ✅
**ファイル**: `public/liff.js`

詳細見積もり送信ボタンを押してから完了画面が出るまでの間、送信中の画面を表示するように修正しました。

**変更内容**:
- `submitAll()`関数の先頭で送信中画面を表示
- 📤アイコンと「送信中...」メッセージを表示

1. **Repository → Show in Finder** でリポジトリフォルダを開く

### 2. コミット&プッシュ

   - Summary: `v16: LINEメッセージ変更、UI改善、送信中画面追加`

### 3. Renderで自動デプロイを確認
5. Renderのダッシュボードでデプロイログを確認
6. ビルドエラーがないことを確認

## ⚠️ 既知の問題

### メール送信が届かない
**問題**: 管理者メールアドレス(matsuo@graphity.co.jp)にメールが届かない

**原因**: RenderのIPアドレスがGmailのSMTPサーバーにブロックされている可能性

**対応策**:
1. **SendGridを使用**(推奨)
   - 無料プラン: 100通/日
   - 設定が簡単
   - Renderとの相性が良い
2. **Gmail以外のSMTPサービスを使用**
   - Mailgun, Amazon SES, Postmarkなど

**現状**:
- LINEメッセージは正常に送信されているので、問い合わせ内容は確認できます
- メール送信は裏で実行されるため、ユーザー体験には影響しません
