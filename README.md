# 外壁塗装見積もりシステム 修正ファイル v11

## 修正内容

### 1. 初回アンケート後のLINEメッセージ変更
**ファイル**: `routes/webhook.js`

友だち追加後(followイベント)に送信されるLINEメッセージを以下の3つの吹き出しに変更:

#### 1つ目の吹き出し
```
外壁塗装オンライン見積もりにご連絡ありがとうございます。
ご連絡いただいた内容の概算見積もりは以下の通りです。

【回答内容】
・お見積もり希望内容
　外壁塗装（回答した内容を掲載）
・築年数
　11〜15年（回答した内容を掲載）
・階数
　2階建て（回答した内容を掲載）
・外壁材
　モルタル（回答した内容を掲載）

概算見積もり金額
¥000,000（計算した金額）
```

#### 2つ目の吹き出し
```
より詳しいお見積もりをご希望の方はこちら。
こちらのフォームに回答いただくと、現地調査での訪問は行わず正確な工事金額をご提示いたします。
ご提示した見積額で発注も可能です。
```

#### 3つ目の吹き出し
ボタンテンプレート:
- タイトル: 「詳細見積もりのご案内」
- テキスト: 「下記ボタンよりお進みください」
- ボタン: 「無料で、現地調査なしの見積もりを依頼」

---

### 2. 構文エラーの修正
**ファイル**: `routes/estimate.js`

LINEメッセージ送信部分の構文エラーを修正。テンプレートリテラルから文字列連結に変更して、エスケープエラーを回避。

---

### 3. leadIdエラーの修正
**ファイル**: `public/liff.js`

leadIdが失われる問題を修正:
- URLパラメータからleadIdを取得した後、**localStorage**に保存
- URLにleadIdがない場合、localStorageから復元
- ページリロードや画面遷移でleadIdが失われないように改善

---

### 4. アップロード画面でのサムネイル表示機能追加
**ファイル**: `public/liff.js`

#### 図面アップロード画面(Step 2/9)
- 立面図、平面図、断面図のファイル選択後、その場で150px×150pxのサムネイルを表示
- 「アップロード済み」のテキストを表示

#### 建物写真アップロード画面(Step 3/9)
- 正面、右側面、左側面、背面のファイル選択後、その場で150px×150pxのサムネイルを表示
- 「アップロード済み」のテキストを表示

---

## ファイル配置方法

### 1. GitHub Desktopを使用する場合

1. **Repository → Show in Finder** でリポジトリフォルダを開く
2. 以下のファイルを配置:
   - `routes/estimate.js` → リポジトリの `routes` フォルダに上書き
   - `routes/webhook.js` → リポジトリの `routes` フォルダに上書き
   - `public/liff.js` → リポジトリの `public` フォルダに上書き
3. GitHub Desktopでコミット:
   - Summary: `v11: LINEメッセージ変更、サムネイル表示追加、構文エラー修正`
4. **Push origin** をクリック
5. Renderで自動デプロイが開始されることを確認

---

### 2. GitHubブラウザを使用する場合

1. https://github.com/glorycolor23-arch/line-paint-estimator を開く
2. 各ファイルを開いて編集ボタン(鉛筆アイコン)をクリック
3. ファイル内容を全て削除して、修正ファイルの内容をコピー&ペースト
4. **Commit changes** をクリック
5. Renderで自動デプロイが開始されることを確認

---

## デプロイ後の動作確認

### 1. LINEメッセージの確認
1. 新しく概算見積もりを完了
2. LINEに届くメッセージを確認:
   - ✅ 1つ目の吹き出し: 回答内容と金額が表示されているか
   - ✅ 2つ目の吹き出し: 詳細見積もりへの誘導文が表示されているか
   - ✅ 3つ目の吹き出し: ボタンで詳細見積もりフォームに遷移できるか

### 2. サムネイル表示の確認
1. 詳細見積もりフォームを開く
2. Step 2/9 (図面のアップロード):
   - ✅ ファイル選択後、その場でサムネイルが表示されるか
3. Step 3/9 (建物の写真):
   - ✅ ファイル選択後、その場でサムネイルが表示されるか

### 3. エラーがないことを確認
1. 詳細見積もりフォームを最後まで入力
2. ✅ エラーが出ないことを確認

## 注意事項

- **leadIdエラー**について: 概算見積もりを完了せずに直接URLを開くとエラーが出ます。これは正常な動作です。
- **Renderの自動デプロイ**: GitHubにプッシュ後、Renderが自動的にデプロイを開始します(通常2〜5分)。
- **デプロイエラー**: もしエラーが出た場合は、Renderのログを確認してください。
