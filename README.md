# v21-v21 変更内容

## 概要
詳細見積もりフォームに見積もり内容の専用ステップを追加し、概算見積もりフォームと同じタップ選択式のデザインにしました。

## 新しいステップ構造

### 変更前（4ステップ）
1. 連絡先（名前、電話、郵便番号、住所、**見積もり項目**）
2. 図面アップロード
3. 写真アップロード
4. 確認画面

### 変更後（8ステップ）
1. **連絡先**（名前、電話、郵便番号、住所）
2. **希望内容**（外壁塗装、屋根工事、外壁塗装と屋根工事）← タップ選択
3. **築年数**（1〜5年、6〜10年...31年以上）← タップ選択
4. **階数**（1階建て、2階建て、3階建て以上）← タップ選択
5. **外壁材**（サイディング、ガルバリウム...わからない）← 画像付きグリッド選択
6. 図面アップロード
7. 写真アップロード
8. 確認画面

## 主な変更点

### 1. 見積もり項目を独立したステップに分離（liff.js）

**変更内容:**
- 連絡先入力から見積もり項目（希望内容、築年数、階数、外壁材）を削除
- 各見積もり項目を独立したステップとして実装
- 概算見積もりフォーム（app.js）と同じデザインを採用

**新しい関数:**
- `renderDesiredWork()`: ステップ2 - 希望内容（タップ選択）
- `renderAgeRange()`: ステップ3 - 築年数（タップ選択）
- `renderFloors()`: ステップ4 - 階数（タップ選択）
- `renderWallMaterial()`: ステップ5 - 外壁材（画像付きグリッド選択）

### 2. タップ選択式ボタンのデザイン

**希望内容、築年数、階数:**
```html
<div class="btn-group-v">
  <button type="button" class="btn-choice">外壁塗装</button>
  <button type="button" class="btn-choice">屋根工事</button>
  <button type="button" class="btn-choice">外壁塗装と屋根工事</button>
</div>
```

- 縦並びのボタングループ
- 選択されたボタンに `selected` クラスが付与される
- タップで即座に選択が反映される

### 3. 画像付きグリッド選択（外壁材）

**外壁材選択:**
```html
<div class="grid-choice">
  <button type="button" class="grid-item">
    <img src="/img/siding.png" alt="サイディング"/>
    <span>サイディング</span>
  </button>
  <!-- 8つの選択肢 -->
</div>
```

- 2列グリッドレイアウト
- 各選択肢に画像とラベルを表示
- ユーザーが外壁材の名前を知らなくても見た目で選択可能
- 概算見積もりフォームと同じ画像を使用（/img/siding.png など）

### 4. ステップ番号の更新

**すべてのステップで badge を更新:**
- ステップ1: `1/8`（連絡先）
- ステップ2: `2/8`（希望内容）
- ステップ3: `3/8`（築年数）
- ステップ4: `4/8`（階数）
- ステップ5: `5/8`（外壁材）
- ステップ6: `6/8`（図面アップロード）
- ステップ7: `7/8`（写真アップロード）
- ステップ8: `8/8`（確認画面）

### 5. 戻るボタンの処理を更新

**各ステップの戻るボタン:**
- ステップ2 → ステップ1
- ステップ3 → ステップ2
- ステップ4 → ステップ3
- ステップ5 → ステップ4
- ステップ6 → ステップ5
- ステップ7 → ステップ6
- ステップ8 → ステップ7

### 6. ファイル名の重複問題を解決（routes/details.js）

**v21-v20からの継続:**
- ファイル名にフィールド名のプレフィックスを追加
- 例: `IMG_8568.png` → `drawing_elevation_IMG_8568.png`
- 7つのファイルすべてがユニークな名前で添付される

## 変更ファイル

### 1. public/liff.js（大幅変更）

**主な変更:**
- `render()` 関数を更新して新しいステップに対応
- `renderContact()` から見積もり項目を削除
- 4つの新しいrender関数を追加:
  - `renderDesiredWork()`
  - `renderAgeRange()`
  - `renderFloors()`
  - `renderWallMaterial()`
- すべてのステップの番号とback処理を更新

**影響範囲:**
- 詳細見積もりフォームの全体構造
- ユーザー体験の大幅改善（入力が簡単に）

### 2. routes/details.js（v21-v20から変更なし）

**既存の変更:**
- ファイル名にプレフィックスを追加してユニークにする

### 3. lib/mailer.js（v21-v20から変更なし）

**既存の変更:**
- ファイル添付処理に詳細なログを追加

## デザインの特徴

### 概算見積もりフォームとの統一性

**CSS クラス:**
- `.btn-group-v`: 縦並びボタングループ（概算フォームと同じ）
- `.btn-choice`: 選択肢ボタン（概算フォームと同じ）
- `.grid-choice`: グリッドレイアウト（概算フォームと同じ）
- `.grid-item`: グリッドアイテム（概算フォームと同じ）
- `.selected`: 選択状態（概算フォームと同じ）

**ユーザー体験:**
- 概算見積もりフォームと同じ操作感
- タップで即座に選択
- 選択状態が視覚的に明確
- 画像で直感的に選択可能

## デプロイ手順

1. 変更ファイルをプロジェクトにコピー:
```bash
cp v21-v21/public/liff.js line-paint-estimator-main/public/
cp v21-v21/routes/details.js line-paint-estimator-main/routes/
cp v21-v21/lib/mailer.js line-paint-estimator-main/lib/
```

2. Gitにコミット&プッシュ:
```bash
cd line-paint-estimator-main
git add public/liff.js routes/details.js lib/mailer.js
git commit -m "v21-v21: 見積もり項目を独立ステップに分離、タップ選択式UI実装"
git push origin main
```

3. Renderで自動デプロイを確認

4. **重要: ブラウザのキャッシュをクリア**
   - LIFFアプリはliff.line.meドメインで動作するため、キャッシュクリアが必須
   - LINEアプリを再起動

## 期待される効果

### ユーザー体験の改善
1. **入力が簡単に**: テキスト入力ではなくタップで選択
2. **視覚的に分かりやすい**: 外壁材を画像で選択可能
3. **一貫性**: 概算見積もりフォームと同じ操作感
4. **ステップが明確**: 各項目が独立したページで分かりやすい

### 入力精度の向上
1. **選択肢が明確**: プルダウンではなくボタンで全選択肢が見える
2. **誤入力の防止**: テキスト入力ではなく選択式
3. **画像で判断**: 外壁材の名前を知らなくても選択可能

### フォーム完了率の向上
1. **心理的負担の軽減**: 1ページあたりの項目数が減少
2. **進捗が明確**: 8ステップ構成で進捗が分かりやすい
3. **戻るボタン**: 各ステップで前のステップに戻れる

## トラブルシューティング

### 新しいステップが表示されない場合
1. ブラウザのキャッシュをクリア（Ctrl+Shift+Delete）
2. LINEアプリを完全に終了して再起動
3. Renderのデプロイログで最新のコミットが反映されているか確認

### 画像が表示されない場合（外壁材ステップ）
1. `/img/` ディレクトリに以下の画像があるか確認:
   - siding.png
   - galvalume.png
   - mortar.png
   - alc.png
   - wood.png
   - rc.png
   - other.png
   - unknown.png
2. 画像のパスが正しいか確認（概算フォームと同じパス）

### ステップ番号がおかしい場合
1. すべてのrender関数でbadgeが正しく更新されているか確認
2. ブラウザのキャッシュをクリア

## 注意事項

### CSSの依存関係
このバージョンは、概算見積もりフォーム（app.js）で使用されているCSSクラスに依存しています:
- `.btn-group-v`
- `.btn-choice`
- `.grid-choice`
- `.grid-item`
- `.selected`

これらのCSSクラスが定義されていることを確認してください（styles.css）。

### 画像ファイルの要件
外壁材ステップで使用する画像は、概算見積もりフォームと同じものを使用します。
画像が存在しない場合、外壁材ステップで画像が表示されません。
