## 🚀 デプロイ手順

### 1. GitHub Desktopでファイルを配置
1. **Repository → Show in Finder** でリポジトリフォルダを開く
2. ZIPファイルを解凍して、**7つのファイル全て**を配置:
   - `public/index.html` → リポジトリの `public` フォルダに上書き
   - `public/app.js` → リポジトリの `public` フォルダに上書き
   - `public/styles.css` → リポジトリの `public` フォルダに上書き
   - `public/liff.js` → リポジトリの `public` フォルダに上書き
   - `routes/estimate.js` → リポジトリの `routes` フォルダに上書き
   - `routes/details.js` → リポジトリの `routes` フォルダに上書き
   - `lib/sheets.js` → リポジトリの `lib` フォルダに上書き

### 2. コミット&プッシュ
- Summary: `v19: 概算見積もりUI改善、送信中画面SVGアニメーション`
- **Push origin** をクリック

### 3. Renderで自動デプロイを確認
- デプロイログを確認
