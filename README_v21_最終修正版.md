## ⚠️ メール送信の問題について

現在、管理者メールが届かない問題が発生しています。

### 対処方法（簡単・推奨）

Renderの環境変数を変更:

1. Render Dashboard → line-paint-estimator → Environment
2. `SMTP_PORT`の値を`587`に変更
3. `SMTP_SECURE`の値を`false`に変更
4. 「Save Changes」をクリック

これでメール送信のタイムアウトエラーが解消されます。

**実装方法:**
- zipcloud API（https://zipcloud.ibsnet.co.jp/）を使用
- 郵便番号7桁を入力すると自動的にAPIを呼び出し
- 都道府県、市区町村、町域を結合して住所欄に自動入力

**エラーハンドリング:**
- API呼び出し失敗時はコンソールにエラーを出力
- ユーザーには影響なし（手動入力可能）
