2. 解凍した`line-paint-estimator-v21-完全版`フォルダの中身を既存のプロジェクトフォルダに上書き

### 2. GitHub Desktopでpush

1. **GitHub Desktop**を開く

2. 変更されたファイルを確認:
   - ✅ `public/index.html`
   - ✅ `public/app.js`
   - ✅ `public/liff.js`
   - ✅ `public/styles.css`
   - ✅ `public/img/elevation_sample.png`（新規）
   - ✅ `routes/details.js`

3. コミットメッセージを入力:
   ```
   v21完全版: 全機能実装（最終確認画面変更、住所入力追加、サムネイル表示、戻るボタン、ローディング画面）
   ```

4. 「**Commit to main**」をクリック

5. 「**Push origin**」をクリック

6. Renderが自動デプロイを開始（約2-3分待つ）

### 3. Renderで手動再デプロイ（重要！）

**なぜ必要？**
- LINEメッセージの内容が更新されない問題を解決するため
- バックエンドの変更を確実に反映するため

**手順:**

1. [Render Dashboard](https://dashboard.render.com/)にログイン

2. 「**line-paint-estimator**」サービスを選択

3. 右上の「**Manual Deploy**」ボタンをクリック

4. 「**Deploy latest commit**」を選択

5. デプロイ完了を待つ（約2-3分）

6. ログで以下のメッセージを確認:
   ```

   ```

## ⚠️ 既知の問題と対処方法

### 問題1: 管理者メールが届かない

**現象:**
- 詳細見積もりフォーム送信後、管理者メール（matsuo@graphity.co.jp）にメールが届かない
- エラーログに「SMTP connection timeout」が表示される

**対処方法A: SMTPポート変更（簡単・推奨）**

Renderの環境変数を変更:

1. Render Dashboard → line-paint-estimator → Environment
2. `SMTP_PORT`の値を`587`に変更
3. `SMTP_SECURE`の値を`false`に変更
4. 「Save Changes」をクリック
5. サービスが自動的に再起動

**対処方法B: SendGrid利用（最も安定）**

詳細は別紙「問題対応ガイド.md」を参照してください。

## 🔧 技術詳細

### ローディング画面のアニメーション

3点波形アニメーション（CSS `@keyframes wave`）:
- 3つのドットが順番に拡大・縮小
- 無限ループで滑らかなアニメーション
- 送信中のユーザー体験を向上

### サムネイル表示の実装

- `FileReader` APIを使用して画像をプレビュー
- `model.thumbnails`オブジェクトでサムネイルを保持
- ステップ間の移動でもサムネイルを維持

### 戻るボタンの実装

- 各ステップでステップ番号を管理
- 戻るボタンクリックで`model.step`をデクリメント
- 選択したファイルは`model.files`に保持
